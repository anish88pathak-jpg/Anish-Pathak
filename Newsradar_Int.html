⚡ Deploy Supabase Edge Function
✕
This is a one-time setup. After this, the Send Digest Now button will send real emails from your Outlook or Gmail.
STEP 1 — Install Supabase CLI
Open Command Prompt or Terminal on your PC and run:
npm install -g supabase
STEP 2 — Create the Edge Function file
Create a file called index.ts inside a folder supabase/functions/send-digest/ and paste this code:
import { serve } from "https://deno.land/std@0.168.0/http/server.ts";
import { SmtpClient } from "https://deno.land/x/smtp@v0.7.0/mod.ts";

serve(async (req) => {
  const { smtp_host, smtp_port, smtp_user, smtp_pass,
          from_email, to_emails, subject, html_body } = await req.json();
  try {
    const client = new SmtpClient();
    await client.connectTLS({
      hostname: smtp_host,
      port: smtp_port,
      username: smtp_user,
      password: smtp_pass,
    });
    for (const to of to_emails) {
      await client.send({
        from: from_email,
        to,
        subject,
        content: html_body,
        html: html_body,
      });
    }
    await client.close();
    return new Response(JSON.stringify({ success: true }), {
      headers: { "Content-Type": "application/json" }
    });
  } catch (e) {
    return new Response(JSON.stringify({ error: e.message }), {
      status: 500, headers: { "Content-Type": "application/json" }
    });
  }
});
STEP 3 — Deploy to Supabase (one command)
In your terminal, run these 3 commands one by one:
supabase login
supabase link --project-ref drrdsmbadfjxvjiwoicz
supabase functions deploy send-digest
✅ Done! Come back and click Send Digest Now — it will work.
💡 Don't have Node.js? Download it free from nodejs.org first, then run the commands above.
