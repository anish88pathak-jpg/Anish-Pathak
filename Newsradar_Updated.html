⚡ Deploy Supabase Edge Function
✕
One-time setup — 5 simple steps. After this, Send Digest Now will send real emails automatically.
STEP 1 — Install Node.js (if not installed)
Download and install from nodejs.org → choose LTS version → install it. Skip this if you already have Node.js.
STEP 2 — Install Supabase CLI
Open Command Prompt (search "cmd" in Windows Start menu) and run:
npm install -g supabase
STEP 3 — Copy the function folder to your Desktop
The download includes a folder called supabase/ — copy it to your Desktop. Then in Command Prompt run:
cd %USERPROFILE%\Desktop
supabase login
supabase link --project-ref drrdsmbadfjxvjiwoicz
STEP 4 — Save your App Password securely
Run this command — replace YOUR_APP_PASSWORD with your real Outlook App Password:
supabase secrets set SMTP_PASSWORD=YOUR_APP_PASSWORD
🔒 Your password is stored securely in Supabase — never visible in code.
STEP 5 — Deploy!
Run this final command:
supabase functions deploy send-digest
✅ When you see "Deployed successfully" — come back and click Send Digest Now!
